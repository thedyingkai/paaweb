# 北京电子科技学院 ACM 校队历史成绩

整理日期：2026-11-11。`records.json` 是公开展示快照，`metadata.json` 保存覆盖范围、来源版本、重复归档和名次差异。学校匹配使用“北京电子科技学院”及对应英文名 Beijing Electronic Science and Technology Institute，排除北京信息科技大学、北京电子科技职业学院等不同学校。

## 数据来源

- [XCPCIO](https://board.xcpcio.com/) 与其 [board-data](https://github.com/xcpcio/board-data) 公共仓库，快照提交 `c7f374b729bb160c73fba1172e8c09306fc5dab0`。核对全部 ICPC / CCPC 队伍与学校文件，并对可用的线下赛提交记录使用 XCPCIO 自身排名引擎重放。
- [CPCFinder 学校页](https://cpcfinder.com/school/611fb81c-32da-4445-970b-a12d69e47039)，公开学校记录 17 条，其中明确标注区域赛 1 银、2 铜。
- [XCPCRating 学校页](https://heimaom.cn/#/school/%E5%8C%97%E4%BA%AC%E7%94%B5%E5%AD%90%E7%A7%91%E6%8A%80%E5%AD%A6%E9%99%A2)，数据生成时间 `2026-11-08T18:05:59.759128+00:00`。检索全部 377 场公开赛事档案，按学校筛出记录。其上游为 [algoux/srk-collection](https://github.com/algoux/srk-collection)。该平台的推算奖牌不直接作为本档案的证据；需要具体奖项或明确奖牌线。

## 统计口径

当前为 60 场比赛、127 条队伍参赛记录，正式奖牌 0 金、5 银、3 铜；打星等效金、银、铜牌各 1 次。页面按学校认定级别与等次展示，采用 `0（+1）` 形式区分正式与打星等效奖项。按比赛队次计数，不把一块团队奖牌乘以队员人数。同场同队的来源合并，来源中真实存在的同名不同队伍保留独立记录。热身赛与网络预选赛不计入奖牌统计。比赛日期采用实际举行日期，跨年举行的赛季保留原标题。

打星等效奖项存于 `equivalentAward`，与正式 `award` 分开。使用 XCPCIO 排名引擎重放原始提交，在正式队伍中比较打星队的等效名次，再对照榜单明示奖牌数量或其指定的 CCPC 比例规则。七条打星记录均完成核对，其中四条未达到奖牌线。`unofficial-equivalents.json` 保留计算名次、奖牌区间及规则；这属于成绩比较，不是实际授奖证明。2026 南昌邀请赛使用原始榜单的 `participant` 邀请赛组作为正式参赛组。

全部 127 条记录均有总队伍数和正式队伍数。CPCFinder 收录的条目使用该平台同一榜单的排名与总数，其余采用 XCPCRating 完整榜单；仅 XCPCIO 收录的 2023 西安邀请赛按其榜单计算队伍数。字段 `teamCountSource` 标明依据，避免混用不同榜单的分子、分母。

按维护者要求，移除所有丝绸之路赛事记录，包括 2019 年南昌联合赛事及 2023—2025 年宁夏理工学院邀请赛。后续整理不重新导入这些条目。2023 年西安邀请赛一条记录仍缺少有效奖牌线，保留参赛情况，等待证明补充。

XCPCIO 2014 年 `wpu_onsite` 与 `nwpu_onsite` 的提交数据逐字节相同，合并为一次比赛；2017 年北京站的占位日期按 XCPCRating 的实际日期校正。不同来源仍有少量名次差异，主表按上述来源优先级展示，元数据保留初次整理的差异，所有来源链接继续可见。

按平台当前范围，只将 ICPC / CCPC 收录项导入本次历史档案；北京市省赛条目保留在研究缓存，不纳入本次发布。天梯赛、联盟主办比赛以及个人自愿登记项目，在这三个来源中没有找到可直接用于本校的完整奖项档案，不填造记录。成员可在个人档案中补充证明，经核验后公开。

这份快照代表三个指定来源的公开收录范围，不宣称已穷尽学校历年所有奖项。历史选手名字来自公开队伍名单，不自动创建用户账号，不据同名自动绑定个人档案。

## 维护

管理员通过 `/api/intro/update` 将 `records.json` 的 JSON 数组作为字符串写入 `honors` 类别，将 `metadata.json` 写入 `honors_meta`。保留未知字段以兼容结构化成绩。新增记录应有稳定 `uid`、赛事、日期、队名及来源；确认奖牌前核验正式参赛资格和赛站奖牌线。

校队成员在 `/team-space` 维护自己的获奖和职务，不直接改写公共历史档案。核验人员可核实原始来源并在必要时更新此快照。

补充队伍数与打星等效奖项使用 `python scripts/besti/enrich_honors.py <研究缓存目录>`；输入需要 `rating-contests/`、`cpc-awards.json`、`standings-evidence.json`。随后执行 `python scripts/besti/recognize_awards.py`，按 `award-recognition.json` 中维护者提供的学校口径换算。重新合并原始数据后应再次运行这两个步骤，并核对移除赛事没有重新出现。

维护者于 2026-11-11 明确：ICPC、CCPC 区域赛和总决赛按国家级，邀请赛按省部级；蓝桥杯国赛按省部级，省赛按校级。金银铜分别对应一二三等奖，原始奖牌保留在 `award`／`equivalentAward` 中，认定级别与等次存于对应的 `Level`／`Grade` 字段。现有正式记录为国家级二等奖 1 次、三等奖 2 次，省部级二等奖 4 次、三等奖 1 次；另有省部级一等奖、二等奖、国家级三等奖的打星等效成绩各 1 次。个人自填奖项允许特等奖、优秀奖，并在选择上述比赛阶段后自动确定级别，后端拒绝与规则冲突的级别。

同日最终确认：比赛保留区域赛、总决赛、邀请赛类别及金牌、银牌、铜牌、优胜奖名称，学校认定单独换算为一、二、三等奖、优秀奖。区域赛与总决赛按国家级，邀请赛按省部级。`contestAward` / `equivalentContestAward` 保存展示用赛事奖项；原始来源的 `award` / `equivalentAward` 不被推算值覆盖，`awardGrade` / `equivalentAwardGrade` 保存学校认定等次。

现有正式优胜奖 31 次，认定为国家级优秀奖 19 次、省部级优秀奖 12 次；另有打星等效优胜奖 4 次，对应国家级等效优秀奖。因此认定奖项共 39 队次，打星等效奖项共 7 队次。原始奖牌仍为 0 金、5 银、3 铜，不把优胜奖计入金银铜牌。原始奖牌未明的 2023 西安邀请赛一条记录仍待核实，网络预选赛保留参赛记录。个人登记 XCPC 时选择金银铜或优胜奖，自动显示学校认定的一二三等奖或优秀奖。

展示补充：打星记录只展示打星标记和等效赛事奖项（金银铜或优胜奖），不逐条显示国家级／省部级等效认定；导出文件同样移除该列。汇总统计仍按原规则在括号内单列打星数量。认定字段继续保留用于汇总计算。
